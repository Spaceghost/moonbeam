# Moonbeam 6.3.0

Moonbeam follows Moonlight's release series with clean version numbers. This
release replays Moonbeam's changes on Moonlight commit `4113dd26` (6.2.0).

- Automatic reconnect keeps retrying with capped backoff, preserves the host
  game, and supports cancellation without quitting it.
- Per-game stream profiles remember resolution, frame rate, bitrate, codec,
  decoder, renderer, HDR and pacing while preserving global defaults.
- NVIDIA Linux users can select hardware decoding with the SDL renderer using
  the validated VAAPI readback path. Automatic decoding retains its prior policy.
- Video self-tests recreate the requested decoder/renderer three times. Isolated
  network fault injection supports repeatable reconnect testing.
- CI builds Windows x64/ARM64 installers and portable packages, universal macOS,
  Linux AppImage and installer bundle, Steam Link and complete source archives.

Native packages are unsigned. Hardware validation results and limitations belong
in the release validation record; build success alone does not establish working
streaming on a target platform.
